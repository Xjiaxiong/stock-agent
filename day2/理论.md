## 理论
问题1: 两者的区别在于，“提示词让模型输出JSON ” 来选择工具 发起动作的是提示词，模型识别，无法做到通用；而原生的 Function Calling 是模型识别，可以做到通用。
问题2: Tool Schema 是什么？ 是关于工具集合的结构化描述，用于描述工具集合，让模型知道工具集合的格式，从而可以调用工具。
问题3: JSON Schema 是什么？ 是关于某个领域的结构化描述，固定的格式定义让沟通和识别变得方便，比起不可控的文字段落更加的标准。
核心是约束工具参数，每个参数比如乐醒，是否必填，描述，可选值等，代码就能校验，少传错参数。
问题4: 一个Tool Result 应该长什么样子？ 工具返回结果时要注意什么？ 一个Tool Result 应该长这样：{ "tool_name": "calculator", "tool_input": "2 + 8", "tool_output": "10" } 工具返回结果的时候要注意格式正确
问题5: 错误处理：工具执行失败时（比如查不到这家公司）应该怎么反馈给模型？直接抛异常让程序崩溃行不行？ 工具执行失败的时候应该按正常的格式返回结果，比如：
{
  "error": "查不到这家公司",
  "message": "暂无 苹果 的行情数据，支持：中际旭创 宁德时代"
} 不能直接抛异常，应该返回结果，让模型知道失败了。
